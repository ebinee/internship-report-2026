05

"비유사단어" 오분류 원인 규명

원인 규명 · 미적용

2612-1차 VN4202627472 / 4020200027460 건 — 국내외 상표명이 사실상 동일한데("CLUB" vs "CLUBS" 한 글자 차이) "비유사단어"로 오분류됨.

get_phrase_status()의 재검증 단계가 상표명을 최대 5단어까지만 이어붙여 비교(make_joined_combinations(max_n=5)). 교집합 자체는 find_all_sequential_matches(단어 수 제한 없음)로 정확히 추출되지만, 9단어짜리 문구를 재검증하는 단계가 5단어 이상은 아예 후보로 만들지도 않아 항상 실패.

별도로, 유사도 등급(1/2/3)은 이 버그와 무관하게 포함관계판단()(완전 일치 여부만 봄)으로 계산되어, 이번 건은 유사도 2로 이미 정상 산정되어 있었음 — 실제 필터링 결과에는 영향 없음.

설계된 수정안 — 기존 5단어 로직은 그대로 두고, 5단어를 넘어 "비유사단어"로 떨어진 phrase만 단어 수 제한 없이 재검사해 "장문일치"라는 별도 값으로 구분. 사용자 요청으로 코드는 적용하지 않고 원복함.

07

홈페이지 필터 실행 포트 오류

수정 완료 (서버)

"필터 실행 실패: 러너 호출 실패" — Analysis2vs.php::_runner_call()이 자기 자신을 https://127.0.0.1/(포트 미지정 → 443)으로 호출하는데, AI 서버는 로컬에 TLS 리스너가 없고 nginx는 8080에서 평문 HTTP만 받는 구조.

ss -tln으로 8080 확인, curl로 x-api-key 인증 포함 200 OK 응답 확인 후 반영.

- $ch = curl_init('https://127.0.0.1/' . ltrim($path, '/'));
+ $ch = curl_init('http://127.0.0.1:8080/' . ltrim($path, '/'));

이미지 업로드 로그 오탐 수정

수정 완료

report_image_upload.py가 unzip -o && chmod -R a+rX를 &&로 묶어 실행 — 이미지 폴더에 다른 계정(llm)이 만든 파일이 섞여 있어 그 파일에 대한 chmod만 권한 거부되고, 이게 전체 국가 스텝을 "해제 실패"로 잘못 표시. 실제로는 업로드/압축 해제 자체는 정상(zip 내용물과 서버 파일 크기·타임스탬프 대조로 확인).

- f"chmod -R a+rX {remote_image_dir}"
+ f"(chmod -R a+rX {remote_image_dir} 2>/dev/null; true)"
