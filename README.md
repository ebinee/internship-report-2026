# reports

취준용 현장실습 작업 리포트 모음. 인턴 GUI 리포지토리와는 별도로 관리한다.

회사 도메인/서버 IP/실명 등 민감 정보는 제거·익명화했다 (`iphuman` → `example`, 공인 IP → 문서용 placeholder, 동료 실명 → "담당자"/"팀원" 등).

모든 리포트는 `assets/style.css` 공용 디자인 시스템(흰 바탕 + 파스텔 블루)을 공유하고, 같은 타임라인/카드 레이아웃으로 통일했다. 리포트를 추가할 땐 이 구조(entry-node · entry-head · entry-body)를 그대로 따를 것.
